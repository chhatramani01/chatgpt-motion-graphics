# Production workflow

1. Define goals, duration, formats, narration, evidence and rights.
2. Choose one of 86 reference styles and fix the style grammar.
3. Create timed storyboard with sound and motion cues.
4. Obtain approval when requested.
5. Implement deterministic `window.seek(t)`.
6. Generate contact sheets and critique typography, flow, transitions and pacing.
7. Render SFX/music/narration on the same clock and mux with FFmpeg.
8. Verify output with ffprobe, check sync, license and final MP4.
