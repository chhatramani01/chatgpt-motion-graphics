Open `prompts/PASTE_IN_CHATGPT.md`, copy its text into a new ChatGPT conversation or Project instructions, and ask for a storyboard. Attach the selected `styles/atlas/<id>/STYLE.md` if ChatGPT cannot access the repository directly. This works as an instructional workflow; it is not a globally installed native skill. An MP4 requires a compatible code execution environment or the local renderer.
