## Start directly in ChatGPT

1. Open [the paste-ready prompt](prompts/PASTE_IN_CHATGPT.md), copy it into a new ChatGPT chat or a ChatGPT Project's instructions.
2. Ask: **“Create a 15-second Whiteboard Explainer about linear regression, with voiceover and synchronized sound effects. Storyboard first.”**
3. Approve the storyboard, then request runnable Canvas/HTML source or an MP4 when execution tools are available.

The style library supplies references, not 86 prebuilt video engines. ChatGPT applies each guide to generate an original animation around your story.

## Run an example

Install Node.js 22+, FFmpeg, and Chromium, then:

```bash
npm install
npx playwright install chromium
npm run check
npm run test:motion
npm run demo
```

The demo renders `output/demo.mp4` and synchronizes a synthesized SFX track. Run `npm run check` for catalog and file integrity checks.
